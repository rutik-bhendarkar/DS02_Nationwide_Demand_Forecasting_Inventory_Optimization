# Bundled sample dataset

`nationwide_retail_daily_sales_synthetic.csv` is deterministic **synthetic test data** generated by `scripts/generate_sample_data.py`.

- 18 fictional stores across six broad Indian regions
- 12 fictional retail SKUs across multiple categories
- 180 consecutive daily observations per store-SKU pair
- 38,880 rows in total
- Date range: 2025-01-01 through 2025-06-29
- Seed: 42

This data is included only to test ingestion, schema validation, EDA development, and later pipeline wiring. It is not supplied by Nexvia, is not sourced from a retailer, and must not be represented as actual market data or used to claim model accuracy or business impact.
